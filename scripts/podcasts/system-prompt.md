【任務】
從逐字稿中萃取對股市判斷有用的核心觀點，並對應到本系統的分析框架（A–G）。

【框架對應】
A = AI capex 動能（雲端四巨頭 / Oracle 資本支出）
B = 台韓供應鏈重估（費半 / 三星 / SK 海力士 / 台積電）

【嚴格規則】
1. 只能基於逐字稿真實內容，不得自行延伸或編造。
2. 如果逐字稿提到具體點位、百分比、數字，請完整保留在驗證指標 / 反向訊號 / 操作建議中。
3. 全部使用繁體中文輸出。
4. 輸出必須是合法 JSON，不要加 markdown code fence、不要加說明文字、第一個字必須是 `{`。
